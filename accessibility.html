Accessibility & Inclusive Design

08

Perceivable

  • Meaningful alt text and SVG titles/descriptions
  • Captions planned for video content
  • Transcripts planned alongside media
  • Sufficient color contrast
  • Text alternatives for every diagram
  • Information never conveyed through color alone

Operable

  • Full keyboard navigation
  • Visible focus indicators
  • Accessible, real buttons for every action
  • No interaction requires a mouse

Understandable

  • Consistent navigation across every page
  • Clear, hierarchical headings
  • Plain, readable language
  • Predictable interaction patterns

Robust

  • Semantic HTML throughout
  • ARIA used only where native semantics fall short
  • Tested against common assistive technologies

WCAG-informed checklist implemented in this site

  • Skip-to-content link on every page
  • Semantic landmarks: header, nav, main, section, footer
  • Descriptive, unique page titles and a logical heading hierarchy
  • Visible focus outlines on every interactive element
  • Keyboard-operable mobile menu, quizzes, slider, buttons, and animation controls
  • prefers-reduced-motion respected for all animation
  • Quiz feedback announced via an ARIA live region
  • SVG diagrams carry a title and description read by screen readers
  • The current page is marked in navigation with aria-current="page" plus bold text and an underline, not color alone

CARP Principles

09
C

Contrast

Serif headings against sans body text, and dark ink against a light paper background, separate levels of the hierarchy at a glance.

A

Alignment

Content sits on a single consistent left edge and a shared content width across every page, so nothing feels randomly placed.

R

Repetition

The same header, footer, card border, and button shape repeat on every page, teaching the eye the pattern once.

P

Proximity

Each question sits directly beside its feedback, and each diagram sits beside the text that explains it.

UDL (Universal Design for Learning)

10

Multiple means of representation

Every concept is presented as text, a labeled diagram, and an interactive model, so a learner can use whichever combination works best for them.

Multiple means of engagement

Sliders, clickable spectrum points, and quiz questions give the learner direct control rather than a single fixed path through the content.

Multiple means of expression

Multiple-choice, true/false, and conceptual questions let a learner demonstrate understanding in more than one format.

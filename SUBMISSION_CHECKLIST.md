# Submission Checklist

## Before submitting / publishing

- [ ] Website is uploaded to a host and has an active, shareable URL
- [ ] All navigation links (desktop and mobile hamburger menu) work correctly
- [ ] `CV.pdf` has been added to `assets/documents/` and the Download CV button opens it
- [ ] `STORYBOARD.md` is complete and reflects the final site
- [ ] `REFLECTION.md` is complete, proofread, and within roughly one page
- [ ] All five interactive artifacts function as intended:
  - [ ] Quantum-confinement slider updates diagram, readouts, and text
  - [ ] Surface-to-volume buttons update the cube diagram and all four readouts
  - [ ] Formative quiz scores correctly and resets correctly
  - [ ] UV-Vis spectrum points are selectable by mouse and keyboard and show correct readings
  - [ ] Electrodynamics animation plays, pauses, and resets correctly
- [ ] Accessibility checklist button opens and closes correctly
- [ ] Keyboard-only pass: every interactive element is reachable and operable with Tab/Shift+Tab/Enter/Space, in a logical order
- [ ] Screen-reader spot check: headings, landmarks, alt text, and SVG titles/descriptions read sensibly
- [ ] Reduced-motion setting suppresses the electrodynamics animation and other non-essential motion
- [ ] Color is never the only way information is conveyed (checked against quiz feedback, correct/incorrect states, and diagrams)
- [ ] Copyright & Fair Use section is accurate for whatever external material (if any) has been added
- [ ] All bracketed placeholders (`[Professional Email]`, `[ORCID Profile]`, `[Google Scholar Profile]`, `[LinkedIn Profile]`, CV/publication placeholders) have been replaced or intentionally left visible as placeholders
- [ ] Mobile test on an actual phone or a narrow browser window: nav collapses to a hamburger, no horizontal scrolling, all buttons are touch-friendly
- [ ] Tablet and desktop widths also checked
- [ ] Spelling and grammar pass across all pages and documents
- [ ] No fabricated credentials, publications, awards, or research results anywhere on the site
- [ ] Every navigation link opens the correct page: Home → `index.html`, About Me → `about.html`, Teaching & Learning → `teaching.html`, Portfolio → `portfolio.html`, Research → `research.html`, Accessibility → `accessibility.html`, CV → `cv.html`, Contact → `contact.html`
- [ ] The active page is visibly marked in the navigation on every page (bold + underline + `aria-current="page"`), not by color alone
- [ ] The logo/name in the header links back to `index.html` from every page
- [ ] Home page's Featured Work cards link correctly into `portfolio.html#artifact-...` anchors
- [ ] Footer's Accessibility, Copyright & Fair Use, and Contact links resolve to the correct pages/anchors
